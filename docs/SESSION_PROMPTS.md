ЗАДАЧА — КАЛИБРОВКА (трек B, шаг 5)
Цель: калиброванная вероятность удержать следующий гейм — среди прогнозов
«65 %» удерживается 65 %, на годах, которых модель не видела. Это и есть цель

1. Остаток по аудиту §11.2, версия 1 — линейный: logit P(hold) =
   logit(p_hold_next живого состояния) + β·z, где z — контекст, известный до

   логистическая регрессия с L2 на обучающих годах; одна модель на три уровня с
   поправкой по уровню.
2. Калибровка поверх — beta или isotonic, подгонка на годах валидации внутри
   обучающих (например, последних), не на тесте. Разбиение по годам опиши в
   плане.
3. Без утечки: признаки гейма — только то, что было известно до его первого
   очка. Тест с отравлением будущего, как в tennis/model/tests/test_game_rows.py
   и tennis/eval/tests/test_live_state.py.
4. Замер на тестовых годах по каждому уровню, 95 % интервал бутстрепом по
